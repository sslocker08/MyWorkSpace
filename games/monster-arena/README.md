# モンスターアリーナ (Monster Arena)

型相性と交代の駆け引きが主役の、ポケモン式ターン制モンスターバトラー。
バトル開始時に **10体のロスターからランダムに3体ずつ** が両者の手持ちに配られ、
相手の手持ちを全滅させたら勝ち。

**単一の自己完結 `index.html`** — ビルド不要。ブラウザで開けばすぐ遊べる。

## 遊び方
- **⚔️ ひとりで遊ぶ（CPU戦）** — その場で遊べる対CPU戦（オフラインでも動く）。
- **🏠 部屋を作る / 🔗 部屋に入る（オンライン）** — PeerJS(WebRTC) の4文字ルームコードで対戦。
  ホストがコードを共有し、相手が入力して接続。※ネット対戦はブラウザ間の直接通信
  （PeerJSブローカーへの接続が必要）。

## 対戦の駆け引き
- **型相性 (RPS)**: 火 > 草 > 水 > 火。効果抜群 ×2 / いまひとつ ×0.5。
- **交代の無償一撃**: 交代はそのターンのアクションを消費し、交代先は相手の技を受ける。引き際の読み合い。
- **ステータス技**: やけど / みずびたし / こんばく / みをまもる / するどさ で布石を打つ。
- **タイプ・モメンタム**: 同じ型の攻撃を連続で当てると与ダメに小ブースト（連撃 ×1.1〜1.2、交代・外し・被弾でリセット）。
- **健全なモンスターは一撃で倒れない**（全快からのワンショット無し）— 読み合いが成立する設計。

## 10体のモンスター
火: ヒノコ / マグマガメ / ボウエン / アシュリュウ ・
水: アワウソ / サンゴモリ / ナミヘビ ・
草: ハッパギツネ / キノコロン / トゲヨウセイ
（各モンスターはインラインSVGで描いた手描き風クリーチャー。バランス型 / タンク型 / 速攻型などの個性を持つ）

## 技術
- Vanilla JS + DOM/SVG（ゲームエンジン不使用）。効果音は Web Audio で合成（音声ファイルなし）。
- ホスト権威のP2Pネットコード（ホストが唯一のシミュレータ＋乱数。参加者はアクションのみ送信し、状態を受け取って描画）。
- バランス検証: `index.html?sim=1&n=2000` でCPU対CPVの自動対戦シミュレーション（バトル長分布・ワンショット有無など）を表示。
- アクセシビリティ: HPは色＋数値の二重表現、`prefers-reduced-motion` 尊重、キーボードフォーカス可視。
