| KIBI-MAGI | 3モデル合議 | 中立審査。仕様・技術・経営思想の3観点で独立検証 | `ThirdParty/` のみ（他は読み取り） |

## 2. KIBI-MAGI の構成（3観点×3モデル）
| 人格 | 観点 | モデル | 割当理由 |
|---|---|---|---|
| **MELCHIOR-1** | 仕様審査：発注書との一致・受入基準の充足・範囲外編集の有無 | **GPT** | 仕様照合・受入基準の網羅チェックに強い |
| **BALTHASAR-2** | 技術審査：実装品質・保守性・テスト可能性・セキュリティ | **GPT** | コードレビュー・技術検証の定評 |
| **CASPER-3** | 経営・思想審査：KIBI憲章/世界観との整合・情報保護・利益相反 | **Claude** | 言語のニュアンス・価値観整合の読み取りに強い |

- **合議**：3人格が独立にレポート→判定は2/3以上で成立。`ESCALATE_TO_HUMAN` は1票でも成立。
- **同門開示**：CASPERはClaude系であり社長室（Claude）と同門。このため CASPER単独の賛成で重大変更を通すことはできず（2/3要件）、思想審査に疑義がある場合はSotaへ上げる。
- **運用**：各人格はSotaが各サービス（ChatGPT＝MELCHIOR・BALTHASAR は**別チャットで独立起動**／Claude別セッション＝CASPER）で起動し、`ThirdParty/README.md` の人格プロンプトと `Cases/<tpr>/inbox/` の審査依頼を与える。出力レポートは `Cases/<tpr>/` に保存（保存代行はSotaまたは社長室。内容の改変禁止）。
- **独立性の担保**：MELCHIOR・BALTHASARは同一モデル（GPT）だが**観点・プロンプト・チャットを分離**して独立に審査する。クロスモデルの相互検証はCASPER（Claude）が担い、社長室（Claude）との同門性は2/3合議と `ESCALATE_TO_HUMAN` の1票成立で相殺する（契約 第10条）。

## 3. 担当の早見表（誰が何をするか）
| 仕事 | 担当 |
|---|---|
| 経営判断・思想判断・ブランド判断・会社構造変更 | Sota（起案＝社長室） |
| 設計・発注書・受入基準・統合・エスカレーション | 社長室 |
| 部署の実務（戦略・商品・EC・発信・営業・経理・法務・庶務） | 各部署AI |
| 技術実装・文書整形・テスト・差分検証（外注分） | Codex Worker |
| 外注成果物の一次検査 | Codex Internal Auditor |
| 社長室の発注・設計・受入の監査 | 社長室の自己監査（兼任）＋重大時はMAGI |
| 内部監査と第三者審査の境界 | 同門の確認＝内部監査／MAGI＝第三者審査。重大変更は後者必須 |
| 最終受入 | 社長室（重大はSota承認） |
