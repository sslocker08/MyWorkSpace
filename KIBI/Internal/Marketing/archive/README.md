## 初期 → 現在：何が残り、何が変わったか

備忘として、当時の思考が現ブランドにどう繋がった／変わったかの見取り図。

### ✅ そのまま核として残ったもの
- **ブランド名 KIBI＝吉備／機微の二重性**（岡山という具体性 × 感情という抽象性）
- **タグライン「こころが還る場所」**
- **3SKU：SOU-ODORI / SEALING NIGHT / PASSED DOWN**（着想源＝よさこい・研究室の夜・剣道）
- **外装ミニマル×内装濃密 / 桐箱・クリアガラス・木製キャップ**
- **香料名で説明せず、気配・余白で語る姿勢**
- **「ありきたり・チープ・AIっぽい」を避ける感性**
- **原点の一文「言葉にできない記憶を、言葉を使わずに手渡したかった」** → 現在の核に直結

### 🔄 変化・収束したもの
- **中核コンセプト**：当時の **「場と間」**（武道家の身体記憶／合図の前の気配）から、現在は **「記憶を蒸留し、感情を翻訳する」** へ収束。
  - ※「場と間」は表のコンセプトからは退いたが、3製品それぞれの源泉（道場・舞台袖・研究室）として内側に生きている。
- **「元武道家」の前面化**：当時は核に据える案もあったが、現在は **「剣士・踊り子・研究者・設計者」の4つの顔**の一つとして相対化。
- **販売トーンの軸**：当時の **「気分で選ぶ（上げる/静める/戻る）」** 接客フレーム → 現在は **記憶・感情の翻訳**を前面に。気分フレームは接客・店頭の補助として有効。
- **ブランド名の再検討（Milieu系・造語案）**：KIBI継続で決着。

### 🗑 採用されなかった主な検討
- ブランド名 Milieu／各種造語案（LIMENA等）
- 作品名 REI-MAE・STAGE LEFT・LINE 等の「場」直結ネーミング
- TPO・機能香水方向（「会議距離でだけ届く」等）
- 単一生活集団（武道×オフィス等）への絞り込み

このアーカイブは「過去の記録」だが、**SNS/noteのコンテンツ源泉**としては今も価値が高い。
