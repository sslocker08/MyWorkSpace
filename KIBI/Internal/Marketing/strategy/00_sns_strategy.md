# KIBI SNS 全体戦略

最終更新：2026-06-05
ステータス：v1（土台）

---

## 0. この戦略の前提

- **最優先ゴール（今期）**：認知拡大・新規フォロワー獲得。まだ知られていないKIBIを「知ってもらう母数」を増やす。
- **運用媒体**：Instagram / X（Twitter）/ TikTok・Reels / note（ブログ）の4つ（認知の主戦場）＋ **LINE公式**（囲い込み・再訪＝ファネル最下層、今期より正式運用）。Threads は検討・最小運用。
- **媒体別の詳細戦略**：各媒体の実施計画は `strategy/platforms/`（[README](platforms/README.md) に横断マップ）。本ファイルは全媒体共通の「憲法」。
- **ブランドの非交渉領域**：急がない。安売りしない。「いい香り」ではなく「記憶の翻訳」を語る。具体的な香料名で押さない。世界観を薄めてまで数字を取りに行かない。

> 認知拡大を狙うが、**世界観を犠牲にしたバズは取らない**。KIBIにとっての「認知」とは、数ではなく「KIBIという固有の世界を一度でも覗いた人」の蓄積。

## 1. ノーススター（全媒体共通の軸）

すべての投稿は、最終的にこの一文に奉仕する。

> **「私のこころが還る場所。感情の機微を香りに。」**

判断に迷ったら問う3つ：

1. これは**感覚を喚起している**か？（状況の説明になっていないか）
2. これは**KIBIにしか言えない**ことか？（一般的な香水アカウントでも言えることなら弱い）
3. これは**急いでいない**か？（煽り・誇張・過剰な明るさは「間」の哲学に反する）

---

## 2. SNSにおけるブランドボイス＆トーン

| 軸 | KIBIである | KIBIでない |
|---|---|---|
| 語り口 | 静か・余白がある・一人称的 | にぎやか・絵文字過多・煽る |
| 視点 | ファウンダーの記憶から出発 | 一般論・トレンド便乗 |
| 言葉 | 詩的・具体的な情景 | スペック羅列・形容詞の安売り |
| 距離感 | そっと差し出す | 売り込む・追いかける |
| リズム | 「間」を置く。墨が水に広がるように | 情報を詰め込む |

**一人称の主体**：基本は「KIBI」または匿名の「ファウンダー」。個人名は出さない（founder.md準拠）。「剣士であり、踊り子であり、研究者であり、設計者」という4つの顔は世界観の資産として使う。

**絵文字**：原則使わない。使うとしても最小限（季節や余白の記号として）。

## 3. コンテンツの5本柱（Content Pillars）

すべての投稿はこのいずれかに属する。認知拡大期は **柱①と柱② を主軸**にする（＝「入口」を広げる）。

### 柱① 記憶のかけら（世界観の入口）★最重要
ファウンダーの記憶＝製品の源泉を、情景として差し出す。総踊りの後の夜、深夜の研究室、秋晴れの道場、倉敷の白壁。
→ **新規が一番ひっかかる入口**。香水を知らない人でも「情景」には反応する。

### 柱② 香りの翻訳（製品の詩）
3製品（SOU-ODORI / SEALING NIGHT / PASSED DOWN）の香りの展開と詩的キャプション。香料名ではなく感情の核心で語る。

### 柱③ ものづくりの手ざわり（制作の裏側）
桐箱、クリアガラス、木製キャップ、OEMとの製品化、調香の言語化。「外装ミニマル×内装濃密」の証拠。
→ 信頼と「本物っぽさ」を醸成。保存・シェアされやすい。

### 柱④ ブランドの哲学（思想）
「記憶を蒸留する」「感情を翻訳する」「急がないこと」。命名哲学。なぜニッチと自称しないか。
→ 深いファンを育てる（note向き）。

### 柱⑤ これからの予感（次作の気配）
倉敷・美観地区の第4・5作（ほうじ茶 / ピーチティー）。完成前から「時間」を共有し、期待を醸成。

## 4. プラットフォーム別の役割設計

4媒体を横並びにせず、**役割を分ける**。同じ素材を媒体ごとに「翻訳」して出す（コンテンツの再利用 ≠ コピペ転載）。

### Instagram ── 世界観のホーム（最重要・認知の受け皿）
- **役割**：KIBIを知った人が最初に訪れて「世界観を確認する」場所。ビジュアルの王道。
- **主柱**：①記憶のかけら / ②香りの詩 / ③ものづくり
- **フォーマット**：フィード（静止画・カルーセル）＋ Reels（発見タブ経由の新規流入）＋ ストーリーズ（日常の温度）
- **認知拡大の鍵**：**Reelsで間口を広げ、フィードで世界観を固める**。リール＝入口、フィード＝着地。

### X（Twitter）── 言葉で世界観を綴る場
- **役割**：詩的な一文、開発思想、記憶の断片を「言葉だけ」で届ける。拡散性で新規接点を作る。
- **主柱**：④哲学 / ①記憶のかけら / ⑤次作の予感
- **フォーマット**：短い詩的ポスト、製品キャプションの分割投稿、スレッドでの思想語り
- **認知拡大の鍵**：1ポスト＝1感覚。引用したくなる「言葉の強度」。

### TikTok / Reels ── 「間」を動かす発見入口
- **役割**：4媒体で最も新規リーチが太い。墨が広がるアニメ、製造背景、ストーリーテリングを動画で。
- **主柱**：①記憶のかけら / ③ものづくり / ②香りの詩
- **フォーマット**：15〜40秒。ASMR的な静けさ、桐箱を開ける所作、情景＋テロップ。
- **認知拡大の鍵**：最初の1.5秒で「間」を提示し、にぎやかなFeedの中で逆に目を引く。**音と静寂のコントラスト**。

### note（ブログ）── 思想を深く沈める場
- **役割**：他媒体で興味を持った人が「もっと知りたい」を満たす最深部。SEO資産にもなる。
- **主柱**：④哲学 / ①記憶のかけら（長文版）/ ⑤次作の物語
- **フォーマット**：1記事1テーマ。ブランド誕生記、各製品の記憶、命名哲学、倉敷の記録。
- **認知拡大の鍵**：検索流入と「保存して読み返される」深度。他媒体からの導線の終着点。

## 5. 媒体間の循環設計（ファネル）

```
TikTok/Reels（広い入口）──┐
X（言葉の拡散）──────────┼──→ Instagram（世界観のホーム）──→ note（最深部・思想）──→ 公式サイト/通販
                          ┘                                                          │
                                                              LINE公式（囲い込み・再訪・リピート）←┘
                                                              ↑ 一度でも触れた人を「忘れさせない」
```

- **新規接点**：TikTok・Reels・Xの拡散
- **着地・確認**：Instagramのプロフィール＆フィード
- **深化**：note
- **転換**：公式サイト（bio・固定リンク経由）
- **保持・再訪**：LINE公式（転換しなかった人・買った人の両方を、急がず繋ぎ留める＝最下層の受け皿）

各媒体のbio/リンクは必ず次の階層へ繋ぐ（媒体別の詳細は `strategy/platforms/`）。

## 6. 認知拡大フェーズ（今期）の重点方針

1. **入口は「情景」で取る**：香水の話から入らない。記憶・場所・感情から入る。香水に興味がない層も情景には反応する。
2. **Reels/TikTokに投資**：新規リーチが最も太い。週の制作リソースの比重を動画に寄せる。
3. **Instagramを「整った世界」に保つ**：新規が必ず確認するので、プロフィールとフィード上部9枚の世界観統一を最優先。
4. **量より「強度」**：1日複数投稿で薄めるより、1投稿の余韻を濃くする。ただし**継続的な接触頻度は確保**（沈黙はブランドを忘れさせる）。
5. **既存資産の最大活用**：brand_genesis / founder / 3製品のstory は宝の山。SNS用に「翻訳」して小出しにする。

## 7. 投稿頻度の目安（v1・要調整）

| 媒体 | 頻度の目安 | 備考 |
|---|---|---|
| Instagram フィード | 週2〜3 | 世界観の質を優先。減らしても整える |
| Instagram Reels | 週1〜2 | 認知の主力。可能な限り維持 |
| Instagram ストーリーズ | 週3〜5 | 軽い温度・舞台裏・リポスト |
| X | 週4〜7（1日1前後） | 言葉なので量を出しやすい |
| TikTok | 週2〜3 | Reelsと素材を共有 |
| note | 月2〜4 | 1本の深さを優先 |

> 無理な頻度で世界観が崩れるより、続けられるリズムを優先。**「急がない」はブランド哲学であると同時に運用の現実解**。

## 8. ビジュアル・トーンの原則（全媒体共通）

- **余白を恐れない**。詰め込まない。
- **色**：クリアガラス、墨、白壁、木、桐の自然色。彩度を抑える。
- **動き**：墨が水に広がるような、ゆっくり・意図的・急がない。
- **文字**：詩的キャプションは約100文字を基準（brand_concept準拠）。具体的な香料名は出さない。
- **一貫性 > 個々の派手さ**。9枚グリッドで見たときに「ひとつの世界」に見えること。

### 音の設計（動画の隠れた主役）
KIBIの「間」の美学は、視覚と同じくらい**音**で決まる。動画では映像より音にコストと注意を割く。
- **撮影はスマホで十分。投資はマイク（音質）へ**。静けさ・所作の音（桐箱を開ける、衣擦れ、水音）を高音質で録る。
- **にぎやかなFeedの中で「静寂」は逆に目を引く**。トレンド音源に乗らず、環境音／余白／間（休符）で勝負する。
- **TTSナレーションは原則使わない**（KIBIの世界観に対し人工音は浮く）。環境音＋テロップを基本に。
- 詳細は `strategy/03_video_sound_guide.md`。

## 9. やらないこと（ガードレール）

- トレンド音源・ミームへの安易な便乗（世界観を薄める）
- 値引き・在庫煽り・「残りわずか」連呼
- 香料スペックの羅列で勝負すること
- 個人名・私生活の過度な露出
- 1.5秒で全部説明しようとすること（間を殺す）

## 10. 効果測定（認知拡大期のKPI）

数字はゴールでなく羅針盤。世界観を曲げてまで追わない。

| 指標 | 見る理由 |
|---|---|
| リーチ / インプレッション（特に新規） | 認知の母数 |
| 保存数・シェア数 | 「持ち帰りたい世界観」かどうか |
| プロフィールアクセス→フォロー転換率 | 着地ページ（IG）の世界観力 |
| note PV・読了率 | 深いファン化の兆候 |
| サイト遷移（bio経由） | 最終的な転換 |

※「いいね数」は最優先指標にしない（世界観ブランドではエンゲージの質が量に勝る）。
