位置づけ：`00_sns_strategy.md`（憲法）と `platforms/`（媒体別戦略）を、**実際に書ける形**に落とした型紙集。

## 0. 共通部品（全媒体・全テンプレで使う）

### 0-1. 公開前チェック（3問）── 1つでも欠けたら出さない
1. **感覚を喚起しているか？**（状況の説明になっていないか）
2. **KIBIにしか言えないか？**（どのブランドでも言える言葉になっていないか）
3. **急いでいないか？**（煽り・誇張・トレンド便乗が滲んでいないか）

### 0-2. 禁止リスト（再掲・機械チェック可能な形）
- 香料名・配合率（「○○を△%」式）
- 値引き・在庫煽り（「今だけ」「残りわずか」「過去最高」）
- 絵文字の多用（原則ゼロ。使っても季節・余白の記号1つまで）
- トレンド音源・ミーム語彙
- 個人名・私生活（主語は「KIBI」または「ファウンダー」）
- 「ニッチフレグランス」という自称

### 0-3. ブランド定型文（コピペ部品）
```
KIBI
キビ｜こころが還る場所
ファウンダーの記憶に刻まれた、｛製品の体験｝。
感情の機微を香りへと落とし込む、日本発のフレグランスブランド。
```

### 0-4. 製品の「源泉スロット」（テンプレに流し込む素材）
各製品の正本から取る。テンプレの｛源泉｝にはここの語彙だけを使う（捏造しない）。
| 製品 | 記憶の出発点 | 感情の核 | 情景の語彙 |
|---|---|---|---|
| SOU-ODORI | よさこい祭りの総踊り。全員がひとつの場に溶け合う | 弾ける喜び・一体感・「続けばいい」と願う夏の夜 | 熱気、境界が消える、夏の夜、祭りの終盤 |
| SEALING NIGHT | 深夜の研究室 | （`../../Development/02 SEALING NIGHT/story.md` 参照） | 紙束、夜の静寂、灯り、封じる |
| PASSED DOWN | 剣道・道場 | （`../../Development/03 PASSED DOWN/story.md` 参照） | 板の間、構え、秋晴れ、受け継ぐ |
| 04 HOJICHA（開発中） | 倉敷・美観地区 | （`../../Development/04 HOJICHA/concept/` 参照） | 白壁、川面、焙じ茶の湯気 |
| 05 PEACH TEA（開発中） | 倉敷・美観地区 | （`../../Development/05 PEACH TEA/concept/` 参照） | 白壁、光、果実の気配 |

> 正確な文言は各 story.md を正本とする。SNS用に要約する際も「感情の核」を変えない。

## 1. Instagram フィード

### 型 IG-1：情景一枚（柱①記憶のかけら）★主力
**構成**：情景写真1枚 ＋ 詩的キャプション約100字 ＋ 余白 ＋ 最小タグ
```
【画像】｛情景写真：彩度低め・余白のある構図。製品は写っても写らなくてもよい｝

【キャプション】
｛情景の一文。体言止めか短い文。説明しない｝

｛感覚の展開2-4行。改行で間を作る。一人称の記憶から｝

｛余韻の一文。願い・問い・静かな断定のいずれか｝

—
｛製品名（出すときのみ）｝
#KIBI #｛世界観タグ2-3個｝ #｛領域タグ2-3個｝
```
**記入見本（SOU-ODORI）**：
> 祭りの終盤、総踊り。
>
> 踊り子も観客も、大人も子供も、
> 溶け合ってひとつになる。
> 境界が消えた瞬間の熱気を、
> いまでも覚えている。
>
> いつまでも続けと願った、夏の夜。
>
> —
> SOU-ODORI
> #KIBI #記憶の香り #間 #香水 #フレグランス

**チェック**：1行目が「説明」になっていないか／100字基準を大きく超えていないか／タグは10個以内か

---

### 型 IG-2：香りの翻訳カルーセル（柱②）
**構成**：5-7枚。1枚目=情景 → 中盤=香りの時間展開（香料名なし） → 終盤=感情の核 → 最終=製品名＋ブランド定型
```
1枚目：｛情景写真＋短い一文（フック。スワイプさせる余白）｝
2枚目：「はじまりは、｛最初の印象の感覚的表現｝」
3枚目：「やがて、｛変化の感覚的表現｝」
4枚目：「最後に残るのは、｛余韻の感覚的表現｝」
5枚目：｛感情の核を一文で｝
6枚目：製品ボトル写真＋製品名＋ブランド定型文（0-3）
キャプション：詩的キャプション正本（story.md）＋タグ
```
**チェック**：時間展開を「トップ/ミドル/ベース」という業界用語で書いていないか（感覚の言葉で）

---

### 型 IG-3：ものづくりカルーセル（柱③）
**構成**：4-6枚。素材・工程・所作を1枚1要素で。保存される「情報設計」を意識
```
1枚目：｛素材・工程の寄り写真＋「なぜ｛素材｝なのか」という静かな問い｝
2枚目以降：1枚＝1つの選択とその理由（桐箱→「大切なものを納める器」等）
最終枚：全体像＋「外装はミニマルに。内側に、濃密を。」等の美学の一文
```
**チェック**：工程自慢・スペック自慢になっていないか（「選択の理由＝思想」を語る）

---

### 型 IG-4：言葉だけ（柱④哲学）
**構成**：無地or淡い紙質感の背景に明朝で一文。スクショ・保存される「言葉のカード」
```
【画像】｛背景：白壁/紙/墨の滲み。文字：明朝・中央or左上に余白を残して配置｝
　　　　｛一文：20-40字。思想・記憶・問いのいずれか｝
【キャプション】｛一文の背景を2-3行で静かに補足（なくても可）｝＋タグ
```
**記入見本**：
> 画像内文字：「急がないこと。それがいちばん遠くまで届く。」

---

### 型 IG-5：ストーリーズ（日常の温度）
**用途**：舞台裏・制作の手元・リポスト・noteやLINEへの案内。フィードより体温高め、ただし世界観内
```
パターンA（舞台裏）：制作の手元写真/短動画＋一言（「今日は瓶詰めの日。」）
パターンB（案内）：新note/新投稿のカード＋「続きを、静かに置いておきます」＋リンク
パターンC（問い）：質問スタンプ「あなたのこころが還る場所は？」（対話の入口・頻度は控えめ）
```

## 2. X（旧Twitter）

### 型 X-1：詩的一文（主食・週4-6）
```
｛情景または感情の一文。20-60字。改行で間を作ってよい｝
```
**記入見本**：
> 祭りのあとの静けさにも、香りがある。
>
> あの夜の熱気が冷めていく、その途中の。

**チェック**：単体で成立する強度があるか／「いい話」一般論になっていないか

### 型 X-2：思想ポスト（週1）
```
｛思想の核を1-3文。「KIBIは〜しない/〜する」という静かな断定が軸｝
｛理由を体験・記憶から1-2文｝
```
**記入見本**：
> KIBIの香りは「いい香り」を目指していない。
> ファウンダーの記憶にある、あの夜・あの場所の感情を翻訳したもの。
> 再現ではなく、翻訳。原文は変わっても、意味は届くように。

### 型 X-3：製品キャプション分割（発売期・連投2-4本）
story.md の詩的キャプションを1文ずつに割り、数時間〜1日おきに置く。最終ポストに製品名と導線。

### 型 X-4：思想スレッド（月1-2・noteへの導線）
```
1/ ｛問いまたは断定で始める（例：なぜ「祭りの後」という名前にしなかったのか）｝
2/〜 ｛1ポスト1メッセージで展開。各ポスト単体で引用に耐える強度｝
末尾/ ｛余韻＋「長い話はnoteに置きました」＋リンク｝
```

### 型 X-5：次作の断片（柱⑤・随時）
```
｛開発中の情景・気配の一文。製品名や発売日は言わない（言える段階まで）｝
（例：倉敷の白壁の前で、ずっと立ち止まっている。）
```

## 3. TikTok / Reels（動画4型｜`03_video_sound_guide.md` 準拠）

> 共通仕様：9:16・15-40秒・環境音主役・TTS禁止・明朝テロップ少量・冒頭1.5秒で「間」を提示・余韻で終わる。

### 型 V-1：所作の30秒（柱③）
```
0.0-1.5s ｛静止に近い画＋所作音の予感（桐箱に手がかかる）。テロップなし｝
1.5-20s  ｛所作：箱を開ける→ボトルを取る→光に透かす。環境音のみ｝
20-28s   ｛テロップ1枚目：「大切なものを納める器。」等、選択の思想を一文｝
ラスト    ｛画を止めて余韻1-2秒。ブランド名小さく｝
```
### 型 V-2：記憶の情景（柱①）
```
0.0-1.5s ｛情景（夜/道場/白壁）＋環境音。動きは最小｝
〜中盤    ｛情景の連なり2-3カット。ゆっくりしたパン｝
テロップ  ｛詩的キャプションを2-3分割でゆっくり表示（合計60-100字）｝
ラスト    ｛無音1秒→製品名 or ブランド名｝
```
### 型 V-3：墨の間（柱④）
```
全編：墨が水に広がる映像（または同質の「間」の映像）＋無音/極小音
テロップ：一文だけ（20-40字）。出すのは中盤以降
```
### 型 V-4：次作の気配（柱⑤）
```
倉敷・美観地区の白壁/川面/光＋環境音（水音・風）＋「いま、つくっています」程度の短テロップ。
製品詳細は言わない。「時間を共有する」ことが目的。
```
**全型共通チェック**：冒頭で説明していないか／カットが速くないか／音が主役になっているか

## 4. note（記事5型）

> 共通仕様：1記事1テーマ・短い段落と余白・冒頭は情景から（説明から入らない）・記事末に静かな導線（サイト/関連記事/LINE）。

### 型 N-1：ブランド誕生記
```
導入：｛ブランド名を出す前に、原風景の情景描写から始める｝
展開：なぜ香りだったのか／「吉備×機微」の二重性／「翻訳」という選択
核心：「記憶を蒸留する」とはどういうことか
余韻：これからのこと（急がない、という宣言）
```
### 型 N-2：製品の記憶（製品ごとに1本）
```
導入：｛記憶の情景をフルで描く（story.mdの長文版）。製品名はまだ出さない｝
転回：その記憶を香りに「翻訳」しようとした話（写実ではない、という葛藤）
展開：香りの時間展開を感覚の言葉で（香料名なし）
核心：感情の核（この香りが「還る場所」である理由）
余韻：製品名・ブランド定型文・静かな導線
```
### 型 N-3：思想エッセイ
テーマ例：「急がないこと」「なぜニッチと自称しないのか」「翻訳と再現の違い」「命名の話」
```
導入：｛具体的な一場面・一つの選択から入る（抽象論から入らない）｝
展開：その選択の裏の思想
接続：製品・ブランドの実例に静かに繋ぐ
余韻：読者への問いかけ（押し付けない）
```
### 型 N-4：ものづくりの記録
桐箱・ガラス・木製キャップ・調香の言語化など、「選択の理由」を1本1テーマで。
### 型 N-5：倉敷の記録（次作連載）
開発の「時間」を共有する連載。進捗報告ではなく、土地と記憶の記録として書く。

## 5. LINE公式（配信5型｜`platforms/line.md` 準拠）

### 型 L-1：あいさつメッセージ（友だち追加時・自動）
```
KIBIへようこそ。

私のこころが還る場所。
記憶を蒸留し、感情を翻訳する香りを、
急がずお届けします。

ときどき、季節の便りと、これからの気配を。
```
### 型 L-2：季節の便り（月1）
```
｛季節の情景一文｝
｛ブランドの近況 or 思想を2-3行。販促なし｝
｛結び：静かな一文。リンクなしでもよい｝
```
### 型 L-3：次作の気配（節目ごと）
```
｛開発の情景を1-2行（倉敷の白壁、試香の夜、など）｝
「すこしずつ、かたちになっています。」
｛note記事があればそっとリンク｝
```
### 型 L-4：note最新のお裾分け（公開時）
```
｛記事の核心を一文で｝
「長い話を、noteに置きました。」＋リンク
```
### 型 L-5：静かなご案内（発売・再入荷時のみ）
```
｛製品の詩的キャプション抜粋（2-3行）｝
｛事実だけ：「○月○日から、お迎えいただけます。」＋リンク｝
※煽り語・限定数の連呼は使わない
```

## 6. 源泉→展開の制作パイプライン（1源泉＝5媒体）

ひとつの源泉（製品の記憶・思想・工程）から、以下の順で展開すると一貫性と効率が最大になる：

```
① note（N-2/N-3）で深く書く ＝ 正本
② noteから抽出 → IGカルーセル（IG-2/IG-3）＋情景一枚（IG-1）
③ noteから抽出 → X分割投稿（X-3）・詩的一文ストック（X-1）
④ 同じ源泉の映像素材 → V-1〜V-4 を撮影・編集
⑤ note公開のタイミングで → LINE（L-4）・ストーリーズ（IG-5 パターンB）
```

> **AI半自動化の接続点**：①の正本と「0-4 源泉スロット」をAIに渡し、②③⑤の下書きを型紙どおりに生成させる。人は「公開前チェック3問」で判定するだけ。詳細は `05_automation_roadmap.md`。
