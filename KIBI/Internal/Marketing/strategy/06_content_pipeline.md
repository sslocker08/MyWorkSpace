# コンテンツ運用パイプライン ── 量産 → 監修 → 公開

最終更新：2026-06-12
位置づけ：`00_sns_strategy.md`（憲法）・`02_post_formats.md`（型紙）・`Internal/Secretary/rules/model-policy.md`（モデル編成）・`Internal/Secretary/rules/review-gate.md`（レビュー関門）を、**日々の制作フローと判断と監督の流れ**に統合した運用手順書。
ステータス：運用文書（社内・部内成果物）。

> 原則：**AIが書いても、公開判断は必ず人（社長）**（`02_post_formats.md §0`）。量産はモデルに、判断は人に。投稿の公開・予約・アカウント操作・DM送信は**自走禁止**（ドラフトまで）。

## 0. パイプライン全体像（5段）

```
① 源泉確定 ──→ ② 量産（下書き）──→ ③ 整え ──→ ④ 監修（二関門）──→ ⑤ 公開（人）
  Sonnet/部長     Haiku             Sonnet      Brand戦略室＋社長   社長のみ
  （何を/どの型）  （型紙に流し込み）  （世界観精度） （3問＋非交渉）    （順序・予約）
                                                          ↑
                                              ⑥ 計測・反映（Sonnet分析）→①へ
```

- **判断と作業の分離**（`model-policy.md §4`）：源泉選定・整え・監修・公開は判断系（人/Sonnet/Opus/社長）、量産は作業系（Haiku）。
- 1源泉＝5媒体展開（`02_post_formats.md §6`）：noteで深く書く＝正本 → IG/X/動画/LINEへ縮約・翻訳。

## 2. 量産（②）の実務 ── Haikuへの渡し方

Haikuに渡すのは「**型紙＋源泉スロット＋禁止リスト**」のセット。捏造を防ぐため、源泉は正本（`02 §0-4` のスロット／各 story.md）の語彙だけを使わせる。

**Haiku向け指示テンプレ**：
```
役割：KIBIの投稿下書きを量産する。判断はしない（整え・公開は別担当）。
型：｛IG-1／X-1／IG-2…｝（02_post_formats.md の該当型）
源泉スロット：｛製品の記憶の出発点・感情の核・情景の語彙（02 §0-4 から。捏造禁止）｝
出力：型紙の穴埋めで下書きを｛N｝案。各案にハッシュタグ案。
禁止：香料名・配合率／値引き・在庫煽り／絵文字多用／トレンド音源・ミーム／個人名・私生活／「ニッチフレグランス」自称／kofukuron23系への言及。
注意：04/05の対外呼称・飲料名・発売日は出さない（「次作」止まり）。
```

- 量産単位：1源泉から複数媒体・複数案をまとめて出させる（A/B比較で整え担当が選ぶ）。
- `/goal` での1週間分一括量産は**この②に限る**（→レビュー待ちに積む）。**公開は自走させない**（`Internal/Marketing/CLAUDE.md`）。

## 3. 監修（④）── 二関門

`02_post_formats.md §0-1` の3問を第一関門、非交渉領域を第二関門とする。**1つでも欠けたら差戻し**。

### 第一関門：公開前チェック3問（部内・全件）
1. 感覚を喚起しているか（状況説明でないか）
2. KIBIにしか言えないか（どのブランドでも言える言葉でないか）
3. 急いでいないか（煽り・誇張・トレンド便乗が滲んでいないか）

### 第二関門：非交渉領域（ブランド戦略室＝Brandが憲法）
- 禁止リスト（`§0-2`）抵触：香料名・配合率／値引き・在庫煽り／絵文字多用／トレンド音源・ミーム／個人名・私生活／自称ニッチ。
- `kofukuron23`/`kofukuron.23`（ポップアップ側）との混同（全件 `@kibi_fragrance` 名義か）。
- 季節適合・製品名の出し方（IG末尾配置／X詩的一文では出さない）。
- **04/05の対外呼称・飲料名・発売日**（jdg-brd-001 確定まで出さない）。
- UGC引用（`Internal/PR/citation-rules.md`：許諾＋クレジット／効能言及不引用／断定見出し回避）。
- 効能寄り表現（薬機/景表）：迷ったら法務（`Internal/PR/citation-rules.md`・req経由）。

### 監修の起票
- 対外カレンダー・大型成果物の世界観監修は **`req-mkt-NNN`（宛先＝ブランド戦略室）** で起票。所見は `Internal/Strategy/review_log/` に返る。
- 部内で閉じる小・中（単発投稿の整え）は部長判断で完結可（`review-gate.md §2 例外`）。

## 4. 公開（⑤）── 関門とクローズ

- **社長レビュー関門**（`review-gate.md`）：対外に出る成果物・大/特大・部長/HQ指定は、`status/Marketing.md` の「成果物（レビュー用）」表に提出（ステータス=レビュー待ち）→ 社長承認（fbk）まで**完了化しない**。
- **公開・予約・アカウント操作・DM送信は社長（人）のみ**。AI/部長は**ドラフトまで**。`/goal`・`/loop` 自律運転中も公開は自走させない。
- 公開順・公開日時は社長判断。カレンダーは「いつ・何を・どの媒体で」の設計であり、実公開の予約ではない。
- note導線は**記事公開後にのみ解禁**（空アカウント誘導の回避＝カレンダー§3）。

---

## 5. 計測・反映（⑥）

- 見る指標（`§10`）：リーチ/インプレ（新規）・保存/シェア・プロフィール遷移→フォロー転換・note PV/読了・サイト遷移。**いいね数は最優先にしない**。
- 反映：分析担当（Sonnet）が月次で整理 → 維持率の高い型・冒頭・源泉を `02_post_formats.md`・`03_video_sound_guide.md` に反映（型は守破離の「守」、データが貯まったら改訂）。
- `/loop` でカレンダー消化確認・数値の定期取り込み（巡回は自走可・公開は不可）。

## 6. 1源泉＝5媒体の標準展開（`02 §6` 運用版）

ひとつの源泉から、この順で展開すると一貫性とコスパが最大：
```
① note（N-2/N-3）で深く書く＝正本（Sonnet整え・Brand監修）
② noteから抽出 → IGカルーセル（IG-2/IG-3）＋情景一枚（IG-1）（②量産→③整え）
③ noteから抽出 → X分割（X-3）・詩的一文ストック（X-1）（②量産→③整え）
④ 同源泉の映像 → V-1〜V-4（撮影＝05_video_plan_tiktok-reels.md）
⑤ note公開タイミングで → LINE（L-4）・IGストーリーズ案内（IG-5 B）
```
> **AI接続点**：①の正本＋源泉スロットをHaikuに渡し、②③⑤の下書きを型紙どおり生成。人は3問で判定。
