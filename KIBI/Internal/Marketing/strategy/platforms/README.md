## 2. ファネル全体図（LINEを正式に組み込んだ版）

```
 ┌─ TikTok/Reels（最も広い入口・発見）─┐
 │                                      │
 ├─ X（言葉の拡散・引用接点）──────────┤
 │                                      ▼
 │                          Instagram（世界観のホーム＝着地・確認）
 │                                      │
 │                                      ├──→ note（深化・思想の最深部）
 │                                      │
 └──────────────────────────────────────┴──→ 公式サイト kibi-fragrance.jp（転換）
                                                        │
                                              LINE公式（囲い込み・再訪・リピート）
                                                ↑ 一度でも触れた人を「忘れさせない」
```

- **入口**（新規リーチ）：TikTok/Reels・X
- **着地・確認**：Instagram（プロフィールと上部9枚で世界観を確定させる）
- **深化**：note
- **転換**：公式サイト
- **保持・再訪**：LINE公式（転換しなかった人・買った人の両方を、急がず繋ぎ留める）

> LINEは「新規の入口」ではなく、**入口で出会った人を逃さないための受け皿**。認知拡大期でも、細く長く育てる。

## 3. 全媒体で共有する素材の循環（再利用 ≠ コピペ転載）

ひとつの記憶・情景・製品から、媒体ごとに「翻訳」して出す。

```
   1つの源泉（例：SEALING NIGHT＝深夜の研究室）
        │
        ├─ note      ：誕生記・記憶の長文（最も詳しい正本）
        ├─ Instagram ：情景写真＋約100字の詩的キャプション／カルーセル
        ├─ Reels/TikTok：所作と環境音の30秒（紙束を揃える音・夜の静寂）
        ├─ X         ：一文の断片を分割投稿／引用される言葉
        └─ LINE      ：上記の中から「深い1本」を、すでに出会った人へそっと届ける
```

制作の原則：**noteで深く書く → 各媒体に縮約・翻訳して展開**すると効率が良い（最深部から逆算）。

## 4. 共通KPI哲学（再掲・各媒体KPIの土台）

数字はゴールでなく羅針盤。世界観を曲げてまで追わない。
- 重視：新規リーチ / 保存・シェア / プロフィール→フォロー転換 / note読了 / サイト遷移
- 軽視：いいね数の絶対値（エンゲージの「質」が「量」に勝る）
- 各媒体ファイルの「固有KPI」は、この哲学を媒体の特性に落とし込んだもの。
