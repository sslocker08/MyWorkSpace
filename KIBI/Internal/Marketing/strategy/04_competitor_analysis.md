# KIBI 競合分解分析

最終更新：2026-06-09
位置づけ：戦略 `00_sns_strategy.md` の補助。認知拡大期に「世界観の伝え方」を競合から学ぶための分析フレーム。

> 着想元：現役クリエイターの実践論「成功したいなら、AIに頼らず競合を10個集めて自分の手で分解分析せよ」。
> **重要な翻訳**：YouTube収益化の文脈では「サムネ・フック・タイトル」を分解するが、
> KIBIが盗むのは **技術レイヤー（可読性・構図・音・字幕）だけ**。
> **世界観・トーンは絶対に模倣しない**（KIBIの価値は固有性。世界観を真似た瞬間に死ぬ）。

---

## 0. 分析の目的とルール

### 目的
- 「香りという見えないものを、SNSでどう世界観として伝えているか」の**手法**を学ぶ。
- 自分たちの盲点（構図・音・字幕・投稿リズム）を競合の成功例から発見する。

### 2つのレイヤー（混同禁止）
| レイヤー | 真似てよいか | 例 |
|---|---|---|
| **技術（HOW）** | ○ 選んで取り入れる | 字幕の可読性、光の作り方、動画の尺、投稿時間、保存されるカルーセル構成 |
| **世界観（WHO/WHY）** | ✗ 絶対に真似ない | トーン、コンセプト、語彙、色設計、ブランドの自己定義 |

### 鉄則
- AIに分析させない。**自分の目で1アカウントずつ分解する**（AIは整理の補助のみ）。
- 「なぜ伸びたか」を推測で言語化する。数字だけ見ない。
- 真似た技術は必ず**KIBIの色で塗り直す**（そのまま流用しない）。

## 2. 分解チェックリスト（1アカウントごとに埋める）

### プロフィール／土台
- [ ] ハンドル・名前（略称で覚えやすいか／固有名と被らないか）
- [ ] bioの構造（何を1行目に置くか、リンク導線）
- [ ] アイコン・ヘッダー（AI臭がないか、世界観の一貫性）
- [ ] ハイライト構成（IG）／固定（X）

### フィード全体（9枚グリッド）
- [ ] 色のトーンは統一されているか
- [ ] 「ひとつの世界」に見えるか／バラバラか
- [ ] 投稿頻度・リズム

### 静止画／カルーセル
- [ ] 1枚目（サムネ）の引きの作り方（※技術として見る、煽りは盗まない）
- [ ] 文字の量・書体・配置・可読性
- [ ] 保存したくなる構成か（情報設計）

### 動画（Reels/TikTok）
- [ ] 冒頭1.5秒のフック（KIBIは「間」で止める／競合は何で止めるか）
- [ ] 尺、カットのテンポ
- [ ] **音**：環境音か／BGMか／トレンド音源か／音量
- [ ] 字幕：書体・サイズ・出すタイミング
- [ ] 終わり方（余韻か／CTAか）

### 言葉／キャプション
- [ ] 1投稿1メッセージか／詰め込みか
- [ ] 香料スペックで語るか／情景で語るか
- [ ] ハッシュタグの使い方（数・種類）

### エンゲージ運用
- [ ] コメントへの対応・固定の仕方
- [ ] 投稿時間帯（伸びている投稿の時間）
- [ ] UGC・お客様の声の扱い方
