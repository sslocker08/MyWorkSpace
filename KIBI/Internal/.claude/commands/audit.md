# 社長チェック（/audit）── 社長室専用

このコマンドは社長室（Internal/ 直下）専用。各部署は自分のサブフォルダで開くため、このコマンドは見えない。

## 実行手順

1. **席の確認**：作業ディレクトリ直下に社長室 `CLAUDE.md`（「KIBI ── 社長室」で始まる）と `Secretary/` があることを確認する。
   無ければ社長室の席ではない。「このコマンドは社長室（Internal/ 直下）専用です。Internal で開き直してください」とだけ返して中止する。
2. **監査本体の読み込み**：`Secretary/templates/audit-prompt.md` を読む。これが監査の正本。
   整合性・運用に加え、**ダッシュボード挙動・レビュー関門（rules/review-gate.md）・タスク処理フロー**の監査（§2b・2c）を含む。
3. **実行**：そのファイルの「---」以降の指示を、あなた（社長＝Fable 5）への指示として最後まで遂行する。
   所見と是正案を出すところまでは読み取り専用。**例外＝§4「HQタスクのクローズ」**：承認済みHQ成果物のタスク締め（自部署 `Secretary/status/HQ.md` のみ）はこの監査で実施してよい（承認は済んでおり記録の確定のため）。
4. **三社体制の点検**：`External/Orders/`・`ThirdParty/Cases/` のステータス停滞、`../Contracts/locks.md` の解除漏れ、Externalの範囲外編集の有無（changed-files と実差分の突合）も監査対象に含める。
5. **承認後**：社長が是正を承認した項目だけを実行し、`Secretary/boards/decisions.md` と該当ステータスに記録する。

$ARGUMENTS があれば、監査の重点（例「連携だけ」「レビュー関門を重点」「HQ締めだけ」）として解釈し、該当領域を厚く見る。
