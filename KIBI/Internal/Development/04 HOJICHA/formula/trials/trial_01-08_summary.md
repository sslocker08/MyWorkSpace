# 作品A — ほうじ茶核アコード探索 試作記録

対象：ほうじ茶ミドル核の探索
試作量：各0.300g（フェーズ単体評価）
香料：リベルタ110種（B群#55〜#84は不使用）

---

## 試作 #1

### 処方

| 素材 | 量 |
|---|---:|
| Hedion 10% | 0.090g |
| Ionon α 10% | 0.030g |
| cis-3-Hexenol 1% | 0.030g |
| Linalool 10% | 0.090g |
| Hay Abs. 10% | 0.060g |

### 評価・学び

- 畳感がある
- cis-3-Hexenolの青臭さが強い → ほうじ茶には不要
- Linaloolが多いと白く・フローラルに出る
- Ionon αはこの量ではパウダリーに出なかった
- Hayは畳感を作れる → **採用継続**

## 試作 #2

### 処方

| 素材 | 量 |
|---|---:|
| Hedion 10% | 約0.170g |
| Ionon α 10% | 約0.033g |
| Linalyl Acetate 10% | 0.010g |
| Coumarine 10% | 約0.011g |
| Vanilin 10% | 約0.013g |
| Linalool 10% | 約0.032g |
| Hay Abs. 10% | 約0.039g |

### 評価・学び

- 青臭さ消えた / 畳感は残っている / 若干の甘みあり / 70点
- **cis-3-Hexenolは不要** → 以降使用せず
- Hay 10% 約0.04gで畳感は出る
- ただし香ばしさはまだない

---

## 試作 #3

### 変更点

#2 + Guaiyl Acetate 1% 約0.012g追加

### 評価・学び

- #2との差がほぼない
- Guaiyl Acetate 1% 0.01gでは香ばしさが出ない
- 増量すると煙・燻製化リスクがある → **主軸にはしにくい**

---

## 試作 #4

### 変更点

#2 + Coffee Abs. 1% 約0.013g追加

### 評価・学び

- Linaloolが強い / ほうじ茶ではない / 茶色くない
- Coffee 1% 約0.01gでは焙煎感はほぼ出ない
- **問題の本質はCoffee不足よりLinaloolの白さ・透明感**
- → **Linaloolをほうじ茶核から外す**

### 処方（Linalool除外、Ethyl Maltol 0.1% / Cacao Abs. 1% 導入）

| 素材 | 量 |
|---|---:|
| Hedion 10% | 約0.172g |
| Ionon α 10% | 約0.037g |
| Linalyl Acetate 10% | 約0.010g |
| Coumarine 10% | 約0.012g |
| Vanilin 10% | 約0.011g |
| Ethyl Maltol 0.1% | 約0.009g |
| Cacao Abs. 1% | 約0.018g |
| Hay Abs. 10% | 約0.038g |

### 評価・学び

- 焦げた甘さが足りない / まだ緑色の茶葉

- Cacaoはあるが少しココア → **最小限なら使える**
- Ethyl Maltol 0.1%は増量余地あり
- Hay 0.04g前後で畳感は出るが緑色の茶葉にも寄る

## 試作 #6

### 処方（Cacao/Coffee/Hay/Ethyl Maltolを前に出した低保留剤ロースト核）

| 素材 | 量 |
|---|---:|
| Hedion 10% | 約0.184g |
| Ethyl Maltol 0.1% | 0.050g |
| Cacao Abs. 1% | 約0.014g |
| Coffee Abs. 1% | 0.030g |
| Hay Abs. 1% | 0.030g |

### 評価・学び

- Hedion感が強い / CacaoとCoffeeの方が感じやすい
- Hedionを核の大部分にするとHedion感が出る
- Hay 1% 0.03gでは茶葉側への引き戻しが不足
- **Coffee 1% 0.03gはコーヒー識別子が出る**

## 試作 #7

### 処方（Cacao抜き、Coffee下げ、Hay増量、Iso E Super導入）

| 素材 | 量 |
|---|---:|
| Hedion 10% | 約0.131g |
| Iso E Super 10% | 約0.052g |
| Ethyl Maltol 0.1% | 0.050g |
| Coffee Abs. 1% | 約0.014g |
| Hay Abs. 1% | 約0.064g |

### 評価・学び

- 色でいうと白い / Hayの畳感が消えた
- **Iso E Superはラストや完成処方の余白材であり、核には不要**
- Hedionも核では少量にとどめるべき
- Hay 1%では畳感が弱い / Coffeeを下げすぎると香ばしさも消える

## 試作 #8

### 処方（保留剤を下げ、Hay/Ethyl Maltol/Coffee/Cacaoを前に出した構成）

| 素材 | 量 |
|---|---:|
| Hedion 10% | 約0.051g |
| Ethyl Maltol 0.1% | 0.080g |
| Cacao Abs. 1% | 0.030g |
| Coffee Abs. 1% | 約0.049g |
| Hay Abs. 1% | 0.090g |

### 評価・学び

- Coffee Abs.は核の主役として不向き / 古いコーヒー豆になる
- Cacaoも茶色さには寄与するがカカオ甘さとして読まれやすい
- **Coffee / Cacao中心のロースト核アプローチは一旦停止**

---

## 試作#1〜#8の総括

### 結論

リベルタ110種だけで写実的なほうじ茶アコードを作るのは難しい可能性が高い。  
ほうじ茶の中核であるピラジン系ロースト香を、CoffeeやCacaoで代替しようとすると、それぞれの識別子が先に立つ。

### 方針転換

```
写実的ほうじ茶
↓
畳、乾いた茶葉、古木、甘い乾き、微かな焙煎記憶
```

「ほうじ茶そのもの」ではなく、**古い美観地区にある、焙煎茶を想起させる乾いた温かい香り**として設計する。

### 次の方向

Hayを茶葉として成立させ、Coumarine / Tonka / Tolu / Vetiverで「焙煎されたように感じる茶葉」を作る。
