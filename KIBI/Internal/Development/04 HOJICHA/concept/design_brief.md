# 作品A（仮：ほうじ茶作品）— 香り設計方針

## 香りの変化軸

```
温かい湯気の予感
→ 乾いた茶葉、畳、甘渋さ
→ 古木、桐箱、静かな余韻
```

## 設計方針

- トップでは、ほうじ茶を完成させすぎない
- 噴霧直後は茶葉そのものよりも、温かい空気・湯気の気配を立たせる
- ミドルで、Hayを中心に乾いた茶葉・畳・紙のような質感を作る
- ラストでは飲み物としてのほうじ茶から離れ、古木・桐箱のような静かな余韻へ移行する
- 食品的な香ばしさではなく、古い空間に包まれる感覚として残す

## 2作品レイヤリング時の役割

ほうじ茶作品を**下**に、ピーチティー作品を上に重ねる。
古い美観地区の乾いた木と茶葉の上に、現代の美観地区の白桃とアールグレイが重なる。
