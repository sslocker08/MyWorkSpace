# 作品B（仮：ピーチティー作品）— 香り設計方針

## 香りの変化軸

```
アールグレイの明るい立ち上がり
→ 白桃ティーと紅茶フローラル
→ 白いウッディムスク
```

## 設計方針

- トップでは、アールグレイとして認識できる明るさを出す
- ミドルでは、紅茶と白桃を分離させず、白桃ティーとして一体化させる
- 桃は甘くしすぎず、黄桃・キャンディではなく白く柔らかい果肉感に留める
- ラストでは甘いフルーツを残しすぎず、白壁・木肌・肌になじむムスクの清潔で穏やかな余韻へ落とす

## 2作品レイヤリング時の役割

ほうじ茶作品を下に、ピーチティー作品を**上**に重ねる。
古い美観地区の乾いた木と茶葉の上に、現代の美観地区の白桃とアールグレイが重なる。
