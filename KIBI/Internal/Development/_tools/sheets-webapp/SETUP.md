# 試作ログ転記API — 設置手順（所要 約10分）

Claudeからスプレッドシートに処方・実測・評価を転記するためのApps Script Webアプリを、
シートのオーナーである **kibi.fragrance@gmail.com** アカウントで設置します。

設置するとできること:
- 合図ひとつで新しい試作列（処方・実測ペア）をシートに追加
- 秤量中にチャットへ入力した実測(g)を、該当セルへ即時記入
- 官能評価メモを評価欄へ転記

ss.locker08@gmail.com の権限は閲覧者のまま変わりません（書き込みはこのスクリプトが
オーナー権限で代行します）。

## 手順

1. **kibi.fragrance@gmail.com でログインした状態で** https://script.google.com を開く
2. 「新しいプロジェクト」→ プロジェクト名を `KIBI 試作ログAPI` などに変更
3. エディタの内容を全て消し、同フォルダの `Code.gs` の中身を貼り付ける
4. 1行目付近の `TOKEN = 'CHANGE_ME_TO_RANDOM_STRING'` を**長いランダム文字列に変更**
   （例: パスワードマネージャで32文字生成。これが実質のパスワードです）
5. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 説明: 任意
   - 次のユーザーとして実行: **自分（kibi.fragrance@gmail.com）**
   - アクセスできるユーザー: **全員**
     （URLとTOKENの両方を知らないと何もできないため、実質的にはTOKENで保護されます）
6. 「デプロイ」→ アクセス承認を求められたら kibi.fragrance アカウントで許可
   （「このアプリは確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」）
7. 表示された **ウェブアプリURL**（`https://script.google.com/macros/s/.../exec`）をコピー
8. URLとTOKENの2つをClaudeとのチャットに貼り付ける
   → Claudeがローカルの `KIBI/.secrets/sheets-webapp.json` に保存し、接続テスト（inspect）を実行します

## セキュリティ上の注意

- **URL + TOKEN の組はシートへの書き込み権限そのもの**。チャット以外の場所
  （メール、メモアプリのクラウド同期等）に貼らないこと
- 保存先 `KIBI/.secrets/` はGit管理外・デプロイ対象外・FileVaultで暗号化済みのローカル領域
- 漏洩が疑われる場合: Apps Script側で TOKEN を変更して「デプロイ」→「デプロイを管理」→ 再デプロイすれば即無効化できる
- このAPIは列の追記とセル記入のみで、既存データの削除・上書き機能を持たない
  （同名試作の二重作成もエラーで拒否）

## コード変更時

`Code.gs` を編集したら、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →
バージョン「新バージョン」→「デプロイ」で反映（URLは変わりません）。
