# 試作 改良サイクル設計（04/05 共通プロトコル）

> 試作 → 香気評価 → 改良 → 再試作 を1本の回路として回すための設計。
> 04 HOJICHA／05 PEACH TEA に共通適用。処方の最終判断は部長止め（自走で確定しない）。
> 参照: `formulation_guide.md`（希釈・力価・IFRA・禁止）／`scent_evaluation_template.md`（評価様式）／各製品 `concept/design_brief.md`（避ける方向）。

---

## 0. サイクル全体図

```
[A] 試作ブリーフ（設計意図・成功基準）        ← AI（香調企画/Opus）
        ↓
[B] 事前チェック（禁止素材・IFRA・在庫）       ← AI（香料データ整理/Haiku→Opus確認）  ※機械確認・違反ゼロが通過条件
        ↓
[C] 秤量シート（×2＝2.000g 推奨）             ← AI生成・人間が実測記入
        ↓
[D] 秤量・EDP化・マセレーション24–48h         ← 人間（物理作業）
        ↓
[E] 香気評価（ブロッター→肌・即時〜24h）       ← 人間が官能、AIが言語化整理
        ↓
[F] 評価の蒸留・改良方針案                     ← AI（香調企画/Opus・試作ログ管理/Sonnet）
        ↓
[G] 改良処方案（次バージョン）                 ← AI起案 → 【部長レビュー】 → 次サイクル[B]へ
```

- 1サイクル＝1試作番号（#1, #2 …）。原則 ×2バッチ（2.000g コンク）で評価。
- **各サイクルは必ず [B] 事前チェックを通す**（処方が変わるたびに禁止素材・IFRA・クマリン/光毒性加算を再判定）。違反が出たら秤量に進ませない。
- **[G] の処方確定判断は部長が止める**。AI は改良「案」までを出し、確定処方への昇格は部長の明示判断で行う。

## 2. 評価→改良の判断ルール（[E]→[F]→[G]）

評価シート §6 の総合判定を起点に分岐する。

| 総合判定 | 次アクション | 改良の粒度 |
|---|---|---|
| ✅ 次フェーズへ（確定候補） | 部長レビューへ上げる。承認で確定処方へ昇格 | 変更なし（再現性確認のみ） |
| 微修正して再試作 | 1–2素材の増減で次サイクル | 1サイクル1–2変数（下記§3） |
| 方向転換が必要 | ブリーフ[A]から見直し。design_brief と突き合わせ | 層単位の再設計 |

### 改良方針の言語化フォーマット（[F]）
評価シート §5「修正方針」に必ず **素材／層・方向（増/減/置換/削除）・理由** の3点で記す。
理由は `design_brief` の「避ける方向」または `formulation_guide` の力価注意に紐づける。

## 3. 一度に変える変数は1–2に絞る（収束のための規律）

- 1サイクルで複数素材を同時に動かすと、効いた要因が切り分けられない。**1試作1–2変数**を原則とする。
- 例外: 層全体の方向転換時のみ層単位で組み替える（その場合は判定「方向転換」扱い）。
- 力価の強い素材（Iso E Super / Ambroxan / Damascon α / Indole 1% / Calone 1% / Guaiyl Acetate / ガルバナム1% / パチュリ1%）は **0.01g刻みで動かす**。1部の増減でも印象が変わる。

## 4. 製品別の収束ターゲット（評価で見る最重要点）

### 04 HOJICHA
- 核は写実ほうじ茶を狙わない（#1–8総括: Coffee/Cacaoロースト核は断念済）。Hay中心＋Coumarine/Tonka/Tolu で「焙煎されたように感じる茶葉」。
- 収束の鍵: ①Cacaoがココアと読まれない（痕跡量を維持）②Coumarine/Tonkaが甘粉化しない ③LASTのHinokiがヒノキ風呂化しない（PASSED DOWN重複回避で少量）④Iso E Superで薄まりすぎない。
- 行き止まり履歴（再現しない）: cis-3-Hexenol（青臭）・Coffee核（コーヒー識別子）・Hedion核大量（Hedion感）。

### 05 PEACH TEA
- 桃は γ-Undecalactone 単独で作らず、果肉・花・果皮・紅茶の乾きに分散。
- 収束の鍵: ①桃がキャンディ/シャンプーにならない ②Damasconが熟れすぎない ③Coumarineが紅茶の乾きとして効く ④LASTのGalaxolideが洗剤化しない・Ambroxanが硬くない ⑤白く落ちる（甘さを残しすぎない）。
- 注意（評価と別管理）: 柑橘比率が高い→光毒性は最終濃度目安内だがグレード確認は仕入/法務へ。EUアレルゲンは当面国内のみで非該当。

## 5. サイクルの終了条件（確定処方への昇格）

次を全て満たしたとき、部長が確定処方候補として社長レビューに上げる。

1. 評価シート §6 が「次フェーズへ」で、**同一処方の再現試作で同じ評価が出る**（再現性）。
2. design_brief の「避ける方向」に寄っていない（§3 ブランド整合 ○）。
3. 事前チェック[B]が禁止素材ゼロ・IFRA全項目クリア（加算含む）。
4. 既存3作との「静けさの質」の差別化が説明できる。

→ 確定後: `formula/formula.md` に正規処方（1.000g コンク・実効濃度併記）を記載し、原価源泉（香料原価精緻化＝req-fin-005）と法務（IFRA本チェック・全成分表示＝req-prd-001/req-lgl-003）へハンドオフ。
