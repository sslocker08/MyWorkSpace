## A. 04/05 物理試作（最優先・嗅覚と秤量が要る）

順序: 再希釈ストック作成 → 秤量 → EDP化 → マセレーション24–48h → 香気評価。

### 04 HOJICHA #1
1. **再希釈ストック2品を作る**（無ければ先に）:
   - Ethyl Maltol 0.1%: 1%品 0.10g + EtOH 0.90g → 1.00g
   - Cacao Abs. 1%: 10%品 0.10g + EtOH 0.90g → 1.00g
2. 秤量（0.01g刻み・タールしながら TOP→MID→LAST）: 表 `04 HOJICHA/formula/trials/trial01_weigh-sheet.md` の **×2列(g)**。19素材。
3. EDP化: コンク2.000g + EtOH11.334g（賦香率15%）。ボトル表記 `HOUJI-CHA #1 / 日付`。
4. マセレーション 24–48h以上。
5. 香気評価: `_GUIDE/scent_evaluation_template.md` をコピー → `04 HOJICHA/formula/trials/trial01_eval.md` に記入（ブロッター→肌・即時〜24h）。

### 05 PEACH TEA #1
1. 再希釈ストック **不要**（全素材10%希釈）。
2. 秤量（同上）: 表 `05 PEACH TEA/formula/trials/trial01_weigh-sheet.md` の **×2列(g)**。22素材。
3. EDP化: コンク2.000g + EtOH11.334g。ボトル表記 `PEACH TEA #1 / 日付`。
4. マセレーション 24–48h以上。
5. 香気評価: 雛形コピー → `05 PEACH TEA/formula/trials/trial01_eval.md` に記入。

> 評価記入後、AI（香調企画/Opus・試作ログ管理/Sonnet）が蒸留して改良方針案を作る（改良サイクル `_GUIDE/iteration_cycle.md` [F]→[G]）。**確定処方の判断は部長止め**。

## B. 評価で必ず見る点（製品別チェックリスト）

### 04 HOJICHA
- [ ] Hayが畳/乾いた茶葉として戻るか（緑色の茶葉に寄りすぎない）
- [ ] Cacaoがココアと読まれない（痕跡量）／Coumarine・Tonkaが甘粉化しない
- [ ] LAST: Cedarが硬すぎない・Iso E Superで薄まりすぎない・Ambrettolideで包容感・Hinokiがヒノキ風呂化しない
- [ ] 避ける方向: コーヒー化/ココア化/燻製/グルマン過多に寄っていないか

### 05 PEACH TEA
- [ ] TOP: アールグレイとして認識できる／Bergamotが精油っぽく出すぎない／Linaloolが石鹸・ラベンダーに寄らない
- [ ] MID: 桃がキャンディ/シャンプーにならない／Damasconが熟れすぎない／Coumarineが紅茶の乾きとして効く
- [ ] LAST: Galaxolideが洗剤化しない・Ambroxanが硬くない・白く落ちる（甘さを残しすぎない）・Hinokiがヒノキ風呂化しない
