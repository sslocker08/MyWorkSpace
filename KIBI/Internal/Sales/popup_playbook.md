# KIBI ポップアップ運用の型（営業部・playbook v1）

> 作成：2026-06-12 ／ 営業部 ／ 初版
> 趣旨：KIBI唯一の実績ある型（QUI・「23の香福論」）を**再現可能な手順**にする。強み③（説明があれば、意図した記憶／感情の核がほぼそのまま伝わる）を最大化する出展の設計図。
> 前提：[channel_strategy.md](channel_strategy.md) §3-F・[proposals/store_proposal_v1.md](proposals/store_proposal_v1.md)・[wholesale_consignment_terms_v1.md](wholesale_consignment_terms_v1.md)。語り口は**ブランドの声**（静か・余白・一人称）＝`../Strategy/tone_and_voice.md`。

## 0. 設計思想 ── 「売り場」ではなく「還る場所」

ポップアップは販売ブースである前に、**こころが還る小さな場所**。
急がない／安売りしない／香料スペックで押さない を、什器・接客・記録のすべてに通す。
「黙って並んで売れる」を目指さない。**語りが介在してこそKIBIは伝わる**ことを前提に設計する。

---

## 1. 什器・しつらえ（外装ミニマル × 内装濃密 を空間で）

| 要素 | 型 | 理由 |
|---|---|---|
| ベース | 余白を多く。商品を詰め込まない（1点ずつ間を置く） | 「間」の哲学を空間で。詰めると工芸性が薄れる |
| 主役の見せ方 | クリアガラス＋木のキャップを、桐箱を開いた状態で1点。テスター（ムエット）を添える | 「大切なものを納める器」の文脈を視覚化 |
| カード | 製品名＋短い詩的キャプションのみ（store_proposal §2）。**香料スペック・効能は書かない** | 香りは仕様書でなく詩として差し出す |
| 香りの試し方 | ムエット（試香紙）中心。原則ボトル直噴霧はしない | 衛生・在庫毀損防止・体験の質 |
| 照明・素材 | 木・紙・墨の質感。明るすぎない | 静けさ・余白の世界観 |
| 価格表示 | 上代¥14,300（税込）を明記。値引き表示は一切しない | 安売りしない（非交渉） |

- **テスターは1本/SKU**（無償＝原価¥3,000/本の持ち出し＝販促費。FIN確認・[wholesale_consignment_terms_v1.md](wholesale_consignment_terms_v1.md) §3）。むやみに増やさない。
- 表示物（カード・POP）の**成分表示・薬機表現は対外掲出前に法務確認**（テスターカード含む）。

## 2. 接客トーン（語りの型＝商品そのもの）

接客は「販売トーク」ではなく「**記憶の翻訳を手渡す語り**」。スジャータ氏・地引氏が「説明されると伝わった」と証言した、その語りを型にする。

### 語りの流れ（おおまかな型・暗記でなく芯）
1. **問いから入る**：「香りを探していますか」ではなく、佇まいに惹かれた相手に「**この箱、開けてみますか**」と間を差し出す。
2. **物語を先に**：香りの前に、その製品が翻訳した記憶を一人称で短く（例：SOU-ODORI＝祭りの終盤、総踊り、境界が消えた幸福）。**再現ではなく翻訳**だと添える。
3. **香りは後から**：ムエットを渡し、相手の沈黙を待つ（間）。こちらから「いい香りでしょう」と言わない。
4. **押さない締め**：「**どこにでも置けるものではないので**」。買わせる言葉でなく、相手に選ばせる余白を残す。

### 言わないこと（非交渉）
- 香料の配合・濃度・ノート構成の専門用語で押す。
- 「今だけ」「お得」「限定割引」など煽り・安売り。
- 効能・医薬的効果（「整える」「落ち着く」等は法務確認なしに自社主語で言わない＝`../PR/citation-rules.md` 準拠）。
- ファウンダーの個人名・私生活の過度な露出（取材時限定ゲート以外では実名を出さない）。

### 語り手
- ファウンダー、または**訓練された語り手**。語りが商品の核なので、誰が立つかが品質を決める。複数人体制なら本playbookと製品キャプションを事前共有。

## 3. 在庫運用（小ロットの現実に合わせる）

| 項目 | 型 |
|---|---|
| 持ち込み本数 | 在庫の現実に厳密に従う。**6〜10月は 03 PASSED DOWN 中心＋7月以降 SOU-ODORI**。02 SEALING NIGHT は残僅少＝持ち込まない（EC温存） |
| 配分との整合 | 7月 SOU-ODORI 100本は EC直販/委託と取り合い。出展持ち込み分は配分（[wholesale_consignment_terms_v1.md](wholesale_consignment_terms_v1.md) §4-1）の中で確保 |
| テスター | 1本/SKU。会期で劣化したら交換（販促費計上） |
| 完売時の約束 | 「**お取り置き／お知らせ**」までに留め、「**常時置けます／すぐ補充できます**」とは言わない（再生産リードタイム未確定＝🔔PRD） |
| 持ち帰り | 桐箱のまま。「ここで還った心を持ち帰る」物語を添える（過剰包装はしない） |

## 4. 記録（次回のための資産化）

会期ごとに1ファイル（`popups/YYYY-MM-DD_会場名.md`・置き場は次回出展時に新設）。**個人情報は書かない**（顧客名簿・連絡先は扱わない／販売記録の正本は本番Blob→`_Records/`＝経理管掌）。

記録する項目（集計・定性のみ）：
- **数値**：会期・会場・出展形態（歩合/出店料）・SKU別 持込/販売/残・テスター消費・概算売上（正本は経理）。
- **定性**：来場者の反応（どの物語が刺さったか）・刺さったキャプション・接客で詰まった点・什器の効き。
- **UGC芽**：その場で生まれた写真・投稿の芽（広報部へ連携。許諾・クレジット前提＝`../PR/citation-rules.md`）。
- **次回への申し送り**：持込本数の過不足・語りの改善・会場との関係。

→ 記録は**次の出展提案の信頼資産**になる（QUI・香福論の実績連鎖がまさにこれ）。
