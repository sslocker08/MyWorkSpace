# targets ── アプローチ先の調査・選定・個別戦略

営業部の職務定義書（`../CLAUDE.md`）が指す置き場。**世界観が合う先だけ**を選ぶ（どこでも置ける展開はしない）。
チャネル定義の正本は [../channel_strategy.md](../channel_strategy.md)。本フォルダは「個別の先ごとの適合性精査＋アプローチ戦略」。

## 命名・運用
- チャネル単位で1ファイル（`channel-A_lifestyle.md` 等）。各ファイル内に候補を「1先1ブロック」で並べる。
- 全候補は **適合性・先方意向ともに未確認**。当たる前に世界観の合致を1件ずつ精査する。
- **店舗送付・商談・DMは自走禁止**（ドラフトまで＝部長確認後）。本フォルダは「誰に・なぜ・どう当たるか」の設計までで止める。

## 適合性スコアの読み方（各候補ブロック共通）
3軸 ◎○△ で素点。**◎が2つ以上＝一次アプローチ群**、△を含む＝保留・要観察。
- **世界観適合**：暮らしのオブジェ／記憶の翻訳／間 が棚に馴染むか。
- **語りの介在**：接客・トーク・しつらえで伝えられる場か（強み③が効くか）。
- **価格維持**：上代¥14,300・委託（値引きなし）を尊重する審美眼があるか。
