# tax ── 確定申告・税務保存

確定申告の準備と、税法上の証憑保存（**7年**）の置き場。

## 保存対象（7年）

- 売上の記録（チャネル別・`../sales-summary/` の集計＋正本は `../../_Records/`）。
- 仕入・経費の証憑：香料（セントピア）、OEM・資材（ピノーレ）、桐箱、決済手数料、送料、出展料 等。
- 各製品・各ロットの原価根拠（`../costing/原価計算表.xlsx`・`../costing/source/`）。
