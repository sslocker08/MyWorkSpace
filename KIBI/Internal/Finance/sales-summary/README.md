# sales-summary ── 販売チャネル別 売上集計

チャネル（**香福論／直販／公式通販EC**）ごとの売上を集計する場所。

## 置いてよいもの / いけないもの

- ✅ 置いてよい：チャネル別・月別の**合計金額・本数などの集計値**（個人を特定できない数字）。
- ❌ 置いてはいけない：**顧客名・属性・個別購入履歴などの個人情報**。それらの正本は `../../_Records/` のみ。

## 集計の元データ

- 正本：本番 Netlify Blobs（`sales-records.json`）＋ローカルバックアップ `../../_Records/sales/`。
- 手順：管理画面からJSONをエクスポート → `../../_Records/sales/` に蓄積 → そこから**集計値のみ**をここに転記。
- 現状：`../../_Records/sales/` は**空**。まず1回目のエクスポートが必要。

## チャネル区分の定義

| チャネル | 内容 | 受取の計算 |
|---|---|---|
| 香福論 | 阪急メンズ東京「23の香福論」期間中の店頭・リモオーダー | 売価 − 阪急マージン33% |
| 直販 | イベント等での直接販売 | 売価 満額 |
| 公式通販EC | kibi-fragrance.jp（Stripe決済） | 通販価格 − Stripe手数料3.6%（送料は自社負担） |
