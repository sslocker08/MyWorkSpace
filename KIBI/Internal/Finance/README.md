# KIBI 経理・財務部 ── フォルダ案内（インデックス）

> 「どこに何があるか迷わない」ための地図。職務定義は [CLAUDE.md](CLAUDE.md)、全社方針は [../CLAUDE.md](../CLAUDE.md)。

## 構成

```
Finance/
├── README.md          ← この地図
├── CLAUDE.md          ← 経理・財務部の職務定義書
├── costing/           ← 原価計算（原価表・粗利・委託コミッション）
│   ├── 原価計算表.xlsx     ← ★メイン成果物（1本あたり原価・チャネル別粗利・ロット別ログ）
│   └── source/             ← 原価の根拠資料（請求書・単価表の控え）置き場
├── sales-summary/     ← 販売チャネル別の売上集計（香福論／直販／EC）
├── pl/                ← 月次の簡易PL（売上・原価・粗利・経費）
└── tax/               ← 確定申告・税務保存（7年）
```

## いちばん大事なルール ── 個人情報の防火壁

- **顧客の個人情報（氏名・属性・購入履歴）は、この `Finance/` 配下に置かない。**
- 個人情報を含む販売記録の正本・バックアップは **`../_Records/` のみ**（Git・デプロイ対象外）。
- `Finance/sales-summary/` に置くのは、個人を特定できない**集計値だけ**（チャネル別・月別の合計など）。
- 外部送信・クラウド共有・クラウドAIへのアップロードは禁止（[../_Records/README.md](../_Records/README.md) の方針を厳守）。

## 各部屋の中身

| フォルダ | 役割 | ステータス（2026-06-11） |
|---|---|---|
| `costing/` | 原価表・チャネル別粗利・委託コミッション早見・ロット別原価ログ | ★着手済（初回ロットの実原価を反映） |
| `sales-summary/` | 香福論／直販／EC のチャネル別売上集計 | 雛形のみ（元データ＝`../_Records` のJSONが必要・現在空） |
| `pl/` | 月次の簡易PL | 雛形のみ（売上データ確定後に着手） |
| `tax/` | 確定申告の準備・証憑の7年保存 | 雛形のみ（仕入総額の連携待ち） |

## いま分かっている数字の前提

- 容量 **50ml EDP（賦香率15%）**／初回製造 **各50本×3種=150本**／OEM＝㈱ピノーレ・香料＝セントピア。
- 売価 **¥14,300（税込）**。公式通販は **¥15,000（税込・送料込み）**。
- 製造原価 **¥3,100/本**（内訳は `costing/原価計算表.xlsx`）。
- チャネル別の受取：香福論は **阪急マージン33%控除後**／直販は**満額**／EC は **Stripe手数料3.6%控除後・送料は自社負担**。
- **原価はロットごとに変動**（香料相場）。新ロットは原価表の「ロット別原価ログ」に追記。
