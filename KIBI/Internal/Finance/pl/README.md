# pl ── 月次の簡易PL（損益）

売上・原価・粗利・主要経費を月次でまとめる場所。

## 構成（予定）

- 売上：`../sales-summary/` のチャネル別集計から。
- 売上原価：`../costing/原価計算表.xlsx` の製造原価 × 販売本数。
- 粗利：売上 − 売上原価。
- 経費：仕入（香料・資材）、OEM、決済手数料、送料、出展料、広告等。
- 営業利益：粗利 − 経費。

## 状態

雛形のみ。`sales-summary/` の売上データと、ファウンダーからの仕入総額が揃い次第、月次PLを起こす。
税込/税抜の扱いは課税区分の確認後に確定（現在は免税事業者前提＝税込ベース）。
