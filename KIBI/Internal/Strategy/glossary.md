## 1. ブランド用語集（正しい表記・意味）

### ブランドの基本

| 用語 | 正しい表記・意味 | 注意 |
|---|---|---|
| ブランド名 | **KIBI（キビ｜こころが還る場所）** | 全大文字。読みは「キビ」 |
| 名の由来 | **吉備**（岡山の旧国名＝場所の具体性）×**機微**（繊細な心の動き＝感情の抽象性）の二重性 | どちらか一方だけにしない。二重性が構造 |
| タグライン | **こころが還る場所** | 確定コピー。改変不可 |
| キャッチコピー | **私のこころが還る場所。／感情の機微を香りに。** | 確定コピー。改変不可 |
| 自己定義 | **「記憶を蒸留する」「感情を翻訳する」プロジェクト** | 「ニッチフレグランス」とは自称しない |
| 掲載済み公式表現 | **こころが還る場所。暮らしのオブジェとして、日常に溶け込むフレグランス。** | QUI掲載文。改変不可・尊重 |

### 思想・キーワード

| 用語 | 意味 | 使いどころ |
|---|---|---|
| 記憶を蒸留する | 体験した場所・時間・感情を出発点に、その核を抽出する | コンセプト説明の中心 |
| 感情を翻訳する | 再現でなく翻訳。原文（記憶）を変えても意味は通じる | 「再現」と言いそうになったらこれ |
| 翻訳であって再現でない | 写実再現を否定する基本姿勢 | 製品説明・取材回答 |
| 間（ま） | 急がない、余白、墨が水に広がる感覚 | ビジュアル・所作・時間設計 |
| 外装のミニマル×内装の濃密 | 表面はシンプル、内側に深い意味 | デザイン・佇まいの説明 |
| 暮らしのオブジェ | 香水としてでなく、置かれている佇まいから始まる作品 | 営業・EC・PR |
| こころが還る | 気分を変えるためでなく、今の自分をそっと確かめる | 体験の言語化 |

### 作り手・製品

| 用語 | 正しい表記 | 注意 |
|---|---|---|
| 作り手 | **ファウンダー** | 個人名・勤務先・私生活は非公開。実名は取材時に限り個別確認 |
| ファウンダーの自己定義 | **剣士であり、踊り子であり、研究者であり、設計者でもある** | 4つで一組。順序固定 |
| 製品名 | SOU-ODORI（総踊り）／SEALING NIGHT（封じる夜）／PASSED DOWN（受け継がれるもの） | ローマ字＋（和名）。01-03 |
| 04／05 | 倉敷・美観地区シリーズ（開発中・命名未確定） | 対外で発売日・処方を出さない。素材名（飲料名）で呼ばない |
| 製品説明の型 | 三段構成＝①香りの説明 ②詩的キャプション（約100字・香料名なし）③ブランド説明定型 | 順序固定 |
| 容器 | クリアガラスボトル／木製キャップ／桐箱 | 桐箱＝「大切なものを納める」 |

### 香りの語り（対外で使ってよい質感語）

香料名・配合率は対外非開示。代わりに**感覚の言葉**で語る。

- 温度（温かい／乾いた／冷たい）・光（白む／差す／透明）・空気（湿り／静けさ／余白）・所作（揃える／綴じる／構える）
- 香調の大枠（フレッシュ／ウッディ／ムスク等）は可。**具体的な香料名（個別の原料名）は不可**。

> 香料名・処方の詳細は製品開発部 `../Development/` が正本。対外には出さない。

## 2. NGワード言い換え表（→ KIBI語）

左を使いそうになったら、右へ翻訳する。番人の差し戻しは「ダメ出し＋代替の言い方」が作法。

### A. 香料スペック語（仕様書化を避ける）

| ✗ NG（スペックで押す） | ○ KIBI語（感覚で語る） |
|---|---|
| ○○（個別の香料名）を△%配合 | 〔香調の大枠＋感覚の質感〕で描く（例：乾いた茶葉の気配） |
| トップ／ミドル／ラストノートは□□ | 〔時間軸の情景〕で（噴霧直後は温かい湯気の予感、やがて古木の余韻へ） |
| 賦香率15%・EDP | 50mL オードパルファン（数値羅列にしない。必要時は仕様欄に淡々と） |
| 天然香料○%・合成○% | （対外で出さない。翻訳された情景で語る） |
| 〔原料名〕の華やかさ | 〔その原料が呼ぶ情景・感情〕（素材でなく記憶で） |

### B. 効能・薬機寄り語（化粧品区分。効能を断定しない）

| ✗ NG（効能・断定） | ○ KIBI語（情景・体験） |
|---|---|
| 癒される／リラックスできる | 今の自分をそっと確かめる時間（効能でなく体験） |
| 気持ちが落ち着く／整う | 心の奥の景色がわずかに揺れる（※QUI引用内の「整える」は引用に留め自社コピー化しない） |
| ストレス解消／安眠／集中力アップ | 〔具体的な記憶の情景〕（深夜の研究室の静けさ 等。効能を主張しない） |
| 治る／改善する／○○に効く | （使用しない。化粧品区分・薬機法。法務 `../Legal/` 参照） |

> 効能寄り表現の最終可否は法務・コンプラ部。QUI掲載の「整える／落ち着く」は**引用体裁に留め、自社の主語で断定しない**（req-lgl-002・req-med-002 の条件）。

### C. 煽り・安売り語（急がない・安売りしない）

| ✗ NG（煽り・希少性の過剰演出） | ○ KIBI語（静かに差し出す） |
|---|---|
| 今だけ／期間限定／お早めに | （急かさない。時期は「整い次第ご案内します」） |
| 残りわずか／売り切れ続出／在庫僅少 | 小ロットの作家もの。ご提案できる本数・時期に制約があります（正直に・静かに） |
| 過去最高／圧倒的／業界No.1／最高級 | （最上級・断定は使わない。第三者の言葉と実績で語る） |
| 半額／○%OFF／値引き／セール | **値引きはしません**（ブランドの姿勢として上代を守る） |
| 大好評につき／話題沸騰／バズ中 | （数で煽らない。第三者がどう受け取ったかを出典付きで添える） |
| 今すぐ／急いで／お見逃しなく | （「間」を壊す。静かな案内に置き換える） |

### D. トレンド便乗・量産語（世界観を薄めない）

| ✗ NG（流行・量産品の語感） | ○ KIBI語 |
|---|---|
| 韓国コスメ風／〇〇み／エモい／尊い | （ミーム・流行語で世界観を薄めない。固有の記憶の言葉で） |
| 万人ウケ／誰でも使える／デイリー使い | 〔特定の記憶・情景〕（KIBIにしか言えないことだけを言う） |
| ピーチティー／ほうじ茶（製品名として） | 倉敷・美観地区シリーズ04／05（飲料名で製品を説明しない。確定名は命名提案参照） |
| バズる／映え／トレンド | （流行に寄せない。静けさと余白を保つ） |
| ニッチフレグランス | 記憶を蒸留し、感情を翻訳するプロジェクト（自己定義を使う） |

### E. 私生活・個人露出語（ファウンダーで統一）

| ✗ NG（過度な露出） | ○ KIBI語 |
|---|---|
| 〔個人名〕／勤務先／私生活エピソード | ファウンダー（実名は取材時に限り個別確認） |
| 代表の日常／オフショット | （香りの出発点となった記憶の情景に限定して語る） |

## 3. 使い方

- 対外発信・コピー・提案資料を出す前に、本表でNG語を点検 → 当たったら右の KIBI語へ翻訳。
- 判断に迷う・新しい言い回しを足したいときは、ブランド戦略室の監修（[worldview_review.md](worldview_review.md) の「監修依頼の受け方」）へ。
- 本表は運用しながら追記する（差分更新）。語の追加・変更はブランド戦略室が確定する。
