## 正本マップ（どの情報の正本がどこにあるか）

世界観の純度を保つため、**理念側（この部屋）と製品実体（製品開発部）を分離**している。

| 情報 | 正本 |
|---|---|
| 理念・世界観・命名哲学・トーン＆ボイス | **Internal/Strategy/**（この部屋） |
| 製品の感情核・名称の意味・世界観監修 | **Internal/Strategy/product_worldview/** |
| 処方・香調・試作ログ・素材 | **[../Development/](../Development/)**（製品開発部） |
| 基本情報・価格・Stripe ID・画像・在庫 | **[../Development/](../Development/)** の `overview.md` ／ EC（[../System/](../System/)） |
| 製品コピー本文（運用） | **[../Development/](../Development/)** の `story.md`（文体監修は Strategy） |

> 原則：**この部屋は処方・価格・IDを持たない。** 製品実体は製品開発部を正本とし、ここはリンクで参照する。

## product_worldview/ について

各製品の**理念側カード**。記憶の出発点・翻訳した感情の核・命名哲学の判定・世界観チェック・正本リンクを持つ。**処方や価格は持たない**（製品開発部 [../Development/](../Development/) が正本）。

- [01_SOU-ODORI](product_worldview/01_SOU-ODORI.md) ／ [02_SEALING-NIGHT](product_worldview/02_SEALING-NIGHT.md) ／ [03_PASSED-DOWN](product_worldview/03_PASSED-DOWN.md)（発売済）
- [04_HOJICHA（仮）](product_worldview/04_HOJICHA.md) ／ [05_PEACH-TEA（仮）](product_worldview/05_PEACH-TEA.md)（開発中・番人ノート）
