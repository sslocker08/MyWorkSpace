## 0. 結論（律速の一点）

**11月中旬・第2回香福論での 04/05 お披露目**が、12ヶ月の主役。これが成立するか否かは、ただ1点 **「04/05の処方確定 → OEM発注締切」**（gate1）に懸かる。
現在 gate1 は **人間（ファウンダー）の物理試作待ち**で止まっている（AI側の準備＝ブリーフ・IFRA事前チェック・評価シートは完了）。**ここが最優先かつ唯一の律速。**

## 1. クリティカルパス（律速チェーン）

```
[gate1] 04/05 処方確定        ← ⛔ 今ここ（物理試作=人間担当。tsk-prd-001 進行中45%）
   │   ※AI準備は完了（ブリーフ/IFRA事前チェック全クリア/評価シート）
   ▼
[A] OEM発注締切（先＝未確定）   ← OEM選定そのものが未決（候補★）／リードタイム・最小ロット・原価が未回答（要確認★）
   │   ※OEM候補：ピノーレ／リベルタ等（リベルタは01-05の香料調合元＝処方継承の親和性あり）。選定は処方確定と同時に社長決定
   │   ※発注Go/No-goは社長決定（OEM先・初回製造本数・01-03再生産要否を同時に）
   ▼
[B] 付帯資材手配（容器/木製キャップ/桐箱/ラベル）  ← 並行手配・資材リードタイムがボトルネック化し得る
   ▼
[C] 04/05 納品（9月末/10月頭）  ← ここが遅れる＝お披露目の核が消える
   ▼
[D] 検品・EC掲載・Stripe登録・ブース設計
   ▼
[E] 第2回香福論（11月中旬・東京）＝04/05お披露目  ← 12ヶ月の主役イベント
   ▼
[F] 第3回(2月・百貨店※未確定)・第4回(5月GW・阪急梅田※未確定)  ← 第2回実績を信頼資産に打診
```

> このチェーンのどこか1つが遅れると、下流すべてが後ろにずれる。**最上流（gate1）に資源を集中**するのが全社最適。

## 5. この依存マップの更新トリガー

- gate1が解除（処方確定・**OEM先決定**・発注締切確定）された時 → クリティカルパスを[A]以降へ進める

- ブロッカー（blk）が解消/発生した時 → W7/W8 等を更新
- 第2回が確定/変更された時 → §1チェーンの日付を確定
