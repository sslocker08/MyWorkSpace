## 全ドラフト共通の遵守事項（書く前のチェック）
- [ ] ファウンダーは匿名（公式表現「剣士・踊り子・研究者・設計者」は可。実名・私生活・勤務先は出さない）
- [ ] 香料名・処方・賦香率を書かない（香りは消費者向け描写とタグまで）
- [ ] 効能・効果をうたわない（薬機法）。「整える／落ち着く」は作り手の願いとして軟化、または QUI 引用体裁に限定（[../citation-rules.md](../citation-rules.md) A項）
- [ ] 最上級・No.1・断定を使わない（景表法）。第三者評価は出典付きで（C項）
- [ ] 未発売 04/05 は「開発中」まで。時期・処方に踏み込まない
- [ ] UGC を引くなら本人許諾・クレジット前提（B項）
- [ ] 煽らず、実績と世界観で静かに。確定コピー「こころが還る場所…」は改変しない
