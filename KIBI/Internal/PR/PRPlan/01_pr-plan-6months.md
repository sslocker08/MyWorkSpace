## 方針（このロードマップが守ること）
- PR は「世界観を覗いてもらう入口」。露出本数を KPI の主にしない。
- 動くのは“きっかけ”が立った時（新作・掲載・取り組み）。きっかけが無い月は**土台を厚くする**。
- 接触順は T1→T2→T3（適合・接点の順）。一斉配信・PRワイヤーはしない。
- 未発売04/05は「開発中」まで。命名・時期・処方に踏み込まない（jdg-brd-001 社長判断待ち）。

## 成果測定（KPI ── 数より質）
露出本数を主目標にしない。次を併記で見る。
| 指標 | 見方 | 備考 |
|---|---|---|
| 掲載・取材の獲得 | 件数より**適合度**（◎媒体での掲載を重く） | T1/T2 での掲載を価値化 |
| 第三者の言葉の蓄積 | 許諾済UGC・掲載の本数と質 | 引用可能な社会的証明の厚み |
| 関係の継続 | 再接触・継続関係の数 | 単発で終わらないこと |
| 世界観の保全 | 逸脱掲載ゼロ | 効能標榜・誇張・実名露出の事故が無いこと（最重要） |
| 流入・反応（参考） | 掲載後のサイト/SNS反応 | マーケ部・Web部の数値を参照（広報単独では追わない） |

> KPI の確定値・数値目標は経営企画室（Planning）の全社KPIと整合させる（必要なら req-med で照会）。
