# メディアリスト v2 ── 階層化版（KIBI）

> 初版（[01_media-list.md](01_media-list.md)・17媒体）を、**優先度ティア／編集枠（デスク）／接点深度／世界観適合**で階層化したもの。
> 用途：接触の順序を意思決定するための作業台。ピッチ下書き（[../PitchEmails/](../PitchEmails/)）と PR計画（[../PRPlan/](../PRPlan/)）の前提になる。
> **数稼ぎの露出はしない**——世界観適合を第一に。実際の送付・配信はドラフト承認後（自走禁止）。初稿 2026-06-12。

## 読み方（凡例）
- **ティア**：T1＝最優先（接点ありor適合◎で早期に動く）／T2＝本命（適合高・プレスキット完成後）／T3＝機会待ち（タイミング・縁ができたら）。
- **世界観適合**：◎＝静けさ・余白・暮らし・工芸・地（岡山/瀬戸内）を正面から扱える／○＝扱える余地あり／△＝枠を選べば可。
- **接点深度**：直＝既存の直接関係／間＝間接（出展・地縁・UGC経由）／無＝接点なし（新規開拓）。
- **編集枠（狙うデスク）**：その媒体の中で KIBI が乗りうる連載・特集・コーナーの型（具体名は接触時に確定）。
- **記者・編集者**：実名連絡先は接触時に個別確定。ここでは「どの担当に当たるべきか」の枠だけ置く（私生活情報・個人連絡先は本リストに転記しない）。

## 接触の順序（T1→T2→T3・無理なく信頼を積む）
1. **T1**：QUI（既存関係）→ 新作・続報のタイミングで再接触。瀬戸内系（間接接点）→ 倉敷シリーズの進展に合わせて。
2. **T2**：&Premium・Discover Japan（適合◎）を先頭に、プレスキット v1.0 完成を機に個別アプローチ。
3. **T3**：節目（新作発売・季節特集・地域企画）で機会を見て個別に。

- 各媒体への送付は**個別に・媒体に合わせて**。一斉配信・PRワイヤーはしない（初版方針を継承）。
- **記者・編集者の実名連絡先は本リストに恒久転記しない**（接触時に個別取得・管理）。私生活情報の保護に準じる。
- UGC由来のレビュアー・お客様（[../Reviews/](../Reviews/)）はメディアではなく**アドボケイト**として別建てで育てる（[../Advocates/](../Advocates/)）。引用は本人許諾・クレジット前提（[../citation-rules.md](../citation-rules.md)）。
