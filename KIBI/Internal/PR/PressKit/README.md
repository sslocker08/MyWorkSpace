## このキットの使い方
- 掲載・取材時は、媒体に合わせて 01 のリード文＋本文から必要部分を抜き、02 の事実で裏を取る。
- **改変してよいのは見出し・リード・分量のみ。** ブランド説明定型文（ボイラープレート）とコピーは原則そのまま使う。
- 数字・日付・実績は必ず 02 ファクトシートを正とする。憶測で補わない。

## 表現の非交渉ルール（全社規範より）
1. **ファウンダーは匿名。** 実名・勤務先・私生活は出さない。公式表現「剣士・踊り子・研究者・設計者」は使用可。
2. **香料名・処方は対外秘。** 製品は消費者向けの香りの描写とタグまで。原料名・賦香率などは書かない。
3. **誇張しない（景表法）。** 「最高」「No.1」等の最上級・断定は使わない。実績は出典付きの事実として示す。
4. **第三者レビュー（UGC）の引用は本人許諾とクレジットが前提。** 無断転載しない。詳細手順＝[../citation-rules.md](../citation-rules.md)（QUI/UGC引用運用ルール）。
5. 煽らず、実績と世界観で静かに語る。確定済みの掲載コピーを尊重する。

## 画像・素材チェックリスト（`assets/`）
プレスキットの三本柱の一つ。現状は未整備。優先度順に準備する。
- [ ] **ブランドロゴ**（高解像度 PNG 透過／ベクター SVG・AI があれば理想）
- [ ] **製品3点の単体写真**（SOU-ODORI / SEALING NIGHT / PASSED DOWN、高解像度・背景白／世界観背景の2種）
- [ ] **桐箱・パッケージ写真**（外装ミニマル×内装、開封の所作が伝わるカット）
- [ ] **ボトルディテール**（クリアガラス＋木製キャップの質感）
- [ ] **3製品集合カット**（ラインナップ一覧用・横位置）
- [ ] **世界観イメージ**（暮らしに置かれた情景。倉敷・美観地区の空気を想起させる引き）
- [ ] 画像クレジット表記の要否・撮影者名の確認

※サイト上の製品画像（webp）は低解像度のEC用。プレス用には別途、高解像度の元データが必要。撮影元データの所在を要確認。
